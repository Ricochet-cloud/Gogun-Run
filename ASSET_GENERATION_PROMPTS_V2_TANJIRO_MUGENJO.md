```
Create a pixel art sprite sheet for Tanjiro Kamado from Demon Slayer.

Character: Tanjiro Kamado (カマド タンジロウ)
- Young demon slayer protagonist
- Distinctive red burgundy hair (short, spiky)

- Style: Pixel art, 8-bit to 16-bit anime style
- Frame size: 48×48 pixels each
- Total frames: 7 frames arranged horizontally
- Canvas: 336×48 pixels (48*7)
- Background: Transparent

Frames (left to right):
1. RUN Frame 1: Running forward, left foot forward, sword slightly behind
2. RUN Frame 2: Running forward, body upright, arms in running motion
3. RUN Frame 3: Running forward, right foot forward, mid-stride
4. RUN Frame 4: Running forward, slight lean, finishing stride
5. JUMP Frame: Jumping upward, both feet off ground, sword raised diagonally, determined expression
6. LAND Frame: Landing impact, knees bent, hands ready, dust effect around feet
7. DEAD Frame: Defeated pose, kneeling on one knee, sword held downward, frustrated expression

Character Details:
- Hair: Bright red-burgundy (#e74c3c to #c0392b), spiky upward style
- Skin: Light peachy tone (#f5deb3)
- Eyes: Red-tinted (#e63946), determined look with black pupils
- Scar: X-shaped scar on forehead in dark red/brown (#8b4513)
- Uniform: Black demon slayer gi (#0a0a0a) with subtle texture
- Haori: Navy/dark blue cloak (#1a1a2e) with subtle patterns
- Sword: Katana with cyan/turquoise blade (#06d6a0 to #00bfff) with metallic sheen
- Hands/Arms: Show skin with determined fists

Animation Notes:
- Running frames: Show natural athletic movement, agile demon slayer
- Jump frame: Should convey strength and determination
- Land frame: Impact pose with energy
- Proportions: Teenage boy (approx 13-15 years old height)
- Expressions: Serious, determined, no smiling

Colors to use:
- Red hair: #e74c3c, #d63031, #c0392b

Quality: Crisp, clear lines; no anti-aliasing (pixel-perfect)
Include: Facial features, hair detail, uniform creases, sword shine effect
Output format: PNG or SVG with transparency
```

## 2️⃣ 배경 패럴랙스 - 무한성 (3층)

### 3.1 원경 (FAR) - 무한성 상단 구조

```
Create a parallax background layer depicting the Infinity Castle (無限城) from Demon Slayer.

Specifications:
- Name: Far Background (원경) - Infinity Castle Upper Structure
- Size: 640×360 pixels
- Style: Pixel art, dark and supernatural
- Background: Transparent (for seamless tiling)
- Must be seamlessly tileable horizontally

Design Concept:
The Infinity Castle (Mugenjo) is a supernatural space created by Upper Moon Six Nakime.
- Impossible architecture with floating structures
- Japanese traditional building elements (columns, beams, stairs)
- Dark color palette with supernatural aura
- Sense of endless, impossible geometry

Upper Portion (0-180px):
- Background sky: Deep purple-black (#1a0033) with supernatural glow
- Color variation: Dark purple (#331a4d), hints of crimson (#4d0000)
- Floating architectural elements:
  - Traditional Japanese wooden beams and columns (#4a3728, #6b5a47)
  - Some beams at odd angles suggesting impossible geometry
  - Carved wooden railings with traditional patterns
  - Small floating wooden platforms at varying heights
- Eerie glow effect:
  - Faint purple/pink glow in some areas (#5d0033, #8b2e5f)
  - Suggestions of supernatural energy
- Floating paper lanterns (#1a0033 with faint glow)

Middle Portion (180-280px):
- More wooden architecture:
  - Traditional Japanese roof tiles (#3d2817, #6b4423)
  - Horizontal wooden beams creating structure
  - Small windows/openings (#0a0a0a with rim light)
  - Interlocking architectural elements suggesting impossible space
- Paper screen doors (shoji) in background (#d4a574, #a0826d)
- Additional purple/dark supernatural haze

Lower Portion (280-360px):
- Dense wooden architectural layers
- Getting darker toward bottom
- Suggestion of endless depth below

Details:
- Color palette (PRIMARY):
  * Dark purple: #1a0033, #2d0052
  * Crimson: #4d0000, #6b0000
  * Wood brown: #4a3728, #6b5a47, #8b6f47
  * Supernatural glow: #5d0033, #8b2e5f
  * Highlights: #d4a574 (wood light)
- Seamless tiling: Left/right edges must perfectly align
- Mood: Dark, eerie, impossible geometry, supernatural realm
- Architecture should suggest Japanese traditional style with twisted, impossible elements
- Include suggestion of endless space/floating architecture

Quality: Crisp pixel art with atmospheric depth
Output format: PNG or SVG (must be perfectly seamless/tileable)
```

## 4️⃣ 바닥 타일 (무한성 버전)

### 📝 프롬포트

```
Create a seamless tileable ground/floor pattern for Infinity Castle theme.

Specifications:
- Name: Infinity Castle Floor Tile (무한성 바닥)
- Size: 64×70 pixels (single tile)
- Style: Pixel art, Japanese traditional with supernatural elements
- Pattern: Repeats horizontally and vertically infinitely
- Background: Transparent

Design:
- Base surface: Traditional Japanese wooden floor (wooden boards)
  - Main color: Dark brown (#6b5a47, #8b6f47)
  - Wood grain effect: Lighter lines (#a89878) and darker shadows (#4a3728)
  - Create texture with horizontal wooden planks
  - Some planks slightly warped/twisted (supernatural distortion)
  
- Decorative elements:
  - Traditional patterns in floor (#a0826d, #8b7a67)
  - Small cracks or imperfections (#3d2817, #2a1f17)
  - Occasional darker spots/stains (#3d0000, #4d0000)
  - Faint purple glow in some areas (#5d0033, subtle)

- Supernatural touches:
  - Slight distortion in some planks suggesting impossible geometry
  - Darker areas that seem to fade away
  - Sense of the floor extending infinitely

Details:
- Must be perfectly seamless:
  - Left edge matches right edge exactly
  - Top edge matches bottom edge exactly
- Color palette:
  * Wood light: #a89878, #d4a574
  * Wood medium: #8b6f47, #8b7a67
  * Wood dark: #6b5a47, #4a3728, #3d2817
  * Shadows: #2a1f17, #1a0f0a
  * Supernatural: #5d0033 (very subtle)
  * Accents: #a0826d

Quality: Crisp pixel art, wooden texture clearly visible
Output format: PNG or SVG (must be perfectly seamless)
```
