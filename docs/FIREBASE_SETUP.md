# Firebase 연결 방법 (한 번만 하면 돼요)

게임 코드는 이미 준비되어 있어요. **Firebase 프로젝트를 만들고 설정값 하나만 붙여넣으면** 로그인·랭킹·기록 저장이 켜져요.
설정 전에는 게임이 지금처럼 기기 안에서만 동작해요.

## 1. 프로젝트 만들기
1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인
2. **프로젝트 추가** → 이름 `gogun-run` → (Google 애널리틱스는 꺼도 됨) → 만들기

## 2. 로그인 켜기
1. 왼쪽 **빌드 → Authentication → 시작하기**
2. **로그인 방법** 탭 → **이메일/비밀번호** 사용 설정 → 저장
3. **설정 → 승인된 도메인** 탭 → **도메인 추가** → `ricochet-cloud.github.io` (GitHub Pages 주소의 앞부분)
   - `localhost` 는 기본으로 들어 있어요.

## 3. 데이터베이스 만들기
1. **빌드 → Firestore Database → 데이터베이스 만들기**
2. 위치: `asia-northeast3 (Seoul)` → **프로덕션 모드로 시작**
3. **규칙** 탭 → 안의 내용을 모두 지우고 `firebase/firestore.rules` 파일 내용을 붙여넣기 → **게시**

## 4. 웹 앱 등록하고 설정값 복사
1. 프로젝트 개요 옆 톱니 → **프로젝트 설정 → 일반 → 내 앱 → 웹(`</>`)**
2. 앱 닉네임 `gogun-run-web` → 등록 (Hosting 체크 불필요)
3. 화면에 나오는 `firebaseConfig = { ... }` 안의 값을 `config/firebase.config.js` 의 `FIREBASE_CONFIG` 에 붙여넣기
4. 저장 → 커밋 → push → 1~2분 뒤 사이트 새로고침

## 5. 랭킹 인덱스
랭킹은 `bestScore` 하나만 정렬하므로 별도 인덱스가 필요 없어요.

## 알아두기
- `apiKey` 등 설정값은 **비밀이 아니에요.** 웹 앱 코드에 공개되는 값이고, 보안은 위 **규칙**이 지켜줘요. 그대로 GitHub에 올려도 돼요.
- 점수는 브라우저에서 계산되기 때문에 개발자도구로 조작이 **가능**해요. 지인끼리 쓰기엔 충분하지만 공개 서비스라면 서버 검증이 필요해요.
- 닉네임 중복은 막지 않아요 (랭킹은 계정 기준).
- 다른 기기에서 로그인하면 서버에 저장된 코인/상점/장착 상태를 불러와요. 최고 점수와 통계는 더 큰 쪽이 유지돼요.
- 로그아웃하면 이 기기의 로컬 기록은 지워져요 (다른 계정과 섞이지 않게). 서버에는 그대로 남아 있어요.
- 무료 요금제(Spark)로 친구 몇 명이 쓰기엔 충분해요.
- 테스트용으로 서버 없이 `?cloud=mock` 을 주소 뒤에 붙이면 이 브라우저 안에서만 가짜 서버로 동작해요.
