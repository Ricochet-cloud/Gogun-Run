# 스프라이트 커터 (tools/sprite-cutter.html)

GPT가 만든 캐릭터 격자 이미지(마젠타 등 단색 배경)를 게임용 스프라이트 시트(64×64 × 7프레임 = 448×64)로 만들고,
**게임에 등록까지 한 번에** 해주는 브라우저 도구입니다. 설치가 필요 없고 이미지는 브라우저 안에서만 처리됩니다.

## 사용법 (Chrome / Edge)
1. `tools/sprite-cutter.html` 을 더블클릭해서 연다.
2. **게임 폴더 연결** → Gogun-Run 폴더를 선택한다. (처음 한 번만. 다음부터는 기억합니다)
3. GPT 이미지를 끌어다 놓는다. 결과 시트, 달리기 미리보기, 경고를 확인한다.
4. 표시 이름 / 설명 / 가격을 입력하고 **게임에 등록**을 누른다.
5. 게임 화면에서 F5 → 타이틀 화면의 캐릭터 선택에 나타난다.

등록하면 도구가 자동으로 해주는 일:
- `assets/player/characters/<id>_448x64.png` 저장
- `assets/player/characters/characters.json` 에 캐릭터 추가 (같은 ID면 교체)

아래쪽 "등록된 캐릭터" 목록에서 순서 변경(▲▼), 정보 수정, 삭제도 할 수 있습니다.
삭제하면 `assets/player/characters/` 안의 PNG도 같이 지웁니다. (그 밖의 기본 에셋 파일은 건드리지 않음)

Firefox처럼 폴더 연결을 지원하지 않는 브라우저에서는 **파일로 받기** 로 PNG와 characters.json 을 받아
`assets/player/characters/` 에 넣으면 됩니다.

## 캐릭터 데이터 형식 (assets/player/characters/characters.json)
| 필드 | 설명 |
|---|---|
| id | 고유 ID (영문/숫자/_) |
| name, desc | 선택 화면에 보일 이름/설명 |
| src | 스프라이트 시트 경로 |
| price | 가격 (0 = 무료). 상점 기능에서 쓸 예약 필드 |
| spriteOverrides | 이 캐릭터만 다른 프레임 크기/오프셋을 쓸 때 (선택) |

잘못된 항목(ID/경로에 허용되지 않는 문자 등)은 게임이 무시하고, 파일을 못 읽으면 기본 캐릭터(탄지로)만 보여줍니다.

## 시트 자동 가공 내용
- 단색 배경 제거 (마젠타 자동 / 직접 고른 색 / 이미 투명한 PNG), 가장자리 분홍 테두리 정리, 잡티 제거
- 칸마다 캐릭터 영역 자동 검출, 모든 프레임에 같은 배율 적용 (달리기 높이 48px)
- 발을 모든 프레임에서 같은 기준선(61행)에 정렬, 가로 중심은 몸통 무게중심에 정렬
- 도트가 뭉개지지 않도록 외곽선 선명하게 처리
