Gogun-Run 스프라이트 커터

GPT가 만든 캐릭터 격자 이미지(단색 배경)를 게임용 스프라이트 시트(64×64 프레임 × 7장 = 448×64)로 자동 변환합니다. 이미지는 브라우저 안에서만 처리되며 어디에도 업로드되지 않습니다.

1. 이미지 불러오기

여기에 이미지를 끌어다 놓거나 클릭
PNG / JPG / WEBP

아직 불러온 이미지가 없습니다.

2. 격자 / 프레임

프레임 순서: 달리기 4장 → 점프 → 착지 → 사망. 칸 순서가 다르면 번호를 바꿔 적으세요. (예: 0,1,2,3,5,4,6)

3. 배경 제거

4. 출력 규격

기본값은 현재 탄지로 시트와 같은 규격입니다. 바꾸면 SPRITE_OVERRIDES가 필요할 수 있어요.

원본 (격자 확인)

빨간 선이 칸 경계입니다. 캐릭터가 선에 걸리지 않게 칸 수를 맞춰주세요.

결과 시트

이미지를 불러오면 여기에 결과가 나타납니다.
달리기 미리보기

    5. 게임에 등록

    게임 폴더를 한 번 연결하면, 아래 버튼 한 번으로 PNG 저장과 캐릭터 목록(characters.json) 갱신이 끝납니다. 등록 후 게임 화면을 새로고침(F5)하면 반영돼요.

    연결 안 됨
    폴더 연결을 못 쓸 때 (Firefox 등) 수동으로 넣는 방법

    ① PNG를 assets/player/characters/ 에 저장 ② 아래 항목을 assets/player/characters/characters.json 의 characters 배열에 추가하세요.

    등록된 캐릭터

    ▲▼ 로 선택 화면 순서를 바꾸고, 수정은 이름·설명·가격을 위 입력칸에 불러옵니다. 삭제하면 PNG 파일도 함께 지워져요. (기본 캐릭터 폴더 밖의 파일은 지우지 않아요)
